# LEGION buyer-first industrial procurement (contract 005)

Buyer entrance: upload CAD/drawing/BOM → explicit BOM extraction (only marked parts) → binding to user requirements → product and manufacturer source preflight → peer demand discovery with consent → direct/AM/split/coalition comparison → individual buyer landed costs → buyer action → Federation/PayPal admission (external).

**What executes locally:** a bounded 2 MB HTTP intake with no CAD retention; CSV/JSON BOM parser; DXF INSERT count (not unknown geometry semantics); explicit SVG BOM annotations; optional extractable PDF BOM text via pypdf; 100 bounded concurrent metadata-preflight tasks (16 threads, 0 external agents); synthetic peer-match and supplier fixture; exact integer-cent allocations; local optional demo-intent journal. It is not a network of 100 actual LLM agents. The old panel remains but this buyer-first entrance is primary.

**What cannot be earned locally:** proof of physical function from an arbitrary CAD upload, independent supplier inventory/price/quote, real buyer ownership/opt-in, supplier commitment, ZTL Engineering proof receipt, Federation admission, checkout authority, PayPal provider readback. These remain Z even for a visually convincing synthetic scenario.

**Required live gate:** engineering=T AND DFM=T AND supplier_quote=T AND capacity=T AND supplier_identity=T AND buyer_optin=T AND all_parties_consent=T AND federation_admission=T AND payment_authority=T. Any F is deny, any Z is hold. Live payment gateway not exposed on new HTTP endpoints. No generated synthetic consent, old PayPal receipt or downloaded screenshot can be used as real authority.

**Supplier plug-in contract (future adapter):** vendor publishes a permissioned read-only endpoint returning exact SKU, process/material/certification, versioned specs, MOQ, capacity, availability epoch, quote bound to buyer destination and currency, taxes, transport, expected delivery, expiry and independently verified vendor identity. No outbound file/drawing sharing without buyer permission. Supplier's assertion alone is not independent verification. The 87 public source records are discovery leads, NOT connected live plugins.

**Buyer-demand plug-in contract (future adapter):** opt-in requests from LEGION and authorized merchant plugins, with specification digest, revision, quantity, budget cap, destination jurisdiction, due date, expiry, consent purpose and revocation epoch. Candidate signals cannot be treated as binding commitments. A buyer with no valid consent does not appear in an executable pool.

**Case 005 synthetic:** New demo buyer uploads BOM for 20 SLS PA12 brackets, same exact spec+revision as four other synthetic buyers ×20. MOQ 100. Group base price 230000 cents plus each buyer's own shipping 2500 cents, plus explicit fixture tax and fee 0. Five all-in shares 48500 cents each; max 78000. Best synthetic route COALITION. Actual commercial gate Z. A demo-only click can optionally persist a local review receipt, never a binding order.
